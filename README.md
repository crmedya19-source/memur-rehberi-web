# Memur Mevzuat Rehberi · web

Bu depo herkese açıktır ve yalnızca şunları barındırır:
- `gizlilik.html` – Gizlilik politikası, yasal uyarı, kullanım koşulları ve kaynaklar (Play Store bağlantısı)
- `haberler.json` – Uygulamadaki Gündem sekmesinin haber listesi
- `app-ads.txt` – AdMob doğrulama dosyası

Uygulamanın kaynak kodu bu depoda değildir.
